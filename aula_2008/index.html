CSS

CSS, ou Cascading Style Sheets (Folha de Estilo em Cascata, em português), é uma linguagem de estilo utilizada para definir a apresentação e o layout de uma página web. Ela é aplicada a documentos HTML para controlar como os elementos da página são exibidos no navegador.


Vantagens

O CSS ajuda a separar a estrutura (HTML) da apresentação, tornando o código mais organizado e fácil de manter.
